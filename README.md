# Manar Market – Single Page Website

React + Vite + Framer Motion. Frontend only.

## Run

    npm install
    npm run dev

## Build

    npm run build

## Editing content

All text, categories, products, hero slides and contact details are in `src/data/content.js`.

## Images

Put photography in `public/images/` using the file names listed in `public/images/README.txt`.
Missing images show a navy-to-green gradient, so the layout never breaks.

## Logo

The logo is currently drawn with text and an SVG mark in the letterhead colours. Replace
`src/components/Logo.jsx` with the official logo file when you have it.

## Palette

- Navy: #03394D
- Green: #2EAA4D
- Deep navy (footer): #022A39
- Light surface: #F5F9F9
